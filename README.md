> **دليل موحد للخدمات والمعلومات الجامعية في المغرب، يعتمد على البيانات المفتوحة والمصادر الرسمية المنشورة.**  
> *مشروع نموذج أولي (MVP) لهاكاثون الابتكار البرمجي والبيانات المفتوحة بالمغرب.*

---

## 📌 1. المشكلة والرؤية
تتوزع معلومات الجامعات العمومية المغربية ومؤسساتها (كليات، مدارس مهندسين، معاهد) بين مواقع متفرقة وروابط قديمة، ما يجعل وصول الطلبة الحاصلين على البكالوريا والطلبة الدوليين وأولياء الأمور إلى المعلومات الرسمية أمراً معقداً.

**رؤية "جامعتي"**: تقديم منصة واحدة تسهّل البحث والاستكشاف، دون استبدال منصات الجامعات، ودون اختلاق أي معلومة، مع التزام تام بالشفافية وإظهار مصدر كل معلومة وتاريخ التحقق منها.

---

## 🏛️ 2. نطاق النسخة الأولى (MVP Scope)
1. **دليل الجامعات والمؤسسات**:
   - **جامعة محمد الخامس بالرباط (UM5)** — موثقة رسمياً.
   - **المدرسة الوطنية العليا للمعلوميات وتحليل النظم (ENSIAS)** — موثقة رسمياً كإحدى مؤسسات جامعة محمد الخامس.
   - **جامعة القاضي عياض بمراكش (UCA)** — موثقة رسمياً.
   - **كلية العلوم والتقنيات جليز (FST-Gueliz)** — موثقة رسمياً.
   - عينات إضافية مصنفة كـ `needs_review` و`demo` لشرح آلية التوسع.
2. **الخريطة التفاعلية (InteractiveMap)**:
   - مبنية بـ **D3.js** ومزودة ببيانات **TopoJSON** المعتمدة من مستودع [yousfiSaad/morocco-map](https://github.com/yousfiSaad/morocco-map) للـ 12 جهة بالمملكة المغربية وفق معيار ISO 3166.
   - دعم التكبير والتصغير وتحديد الجهات والمدن تفاعلياً وتصفية الدليل المباشر بنقرة واحدة.
3. **البحث والتصفية الفورية**: بالاسم، المدينة، نوع المؤسسة، وحالة التوثيق.
4. **بطاقة تفاصيل لكل مؤسسة**: الروابط الرسمية، التبعية للجامعة الأم، الشعب والتكوينات، وشروط الولوج.
5. **توثيق المصدر وتاريخ المراجعة**: لكل سجل حقول `source_url`, `source_name`, `verified_at`, `data_status`.
6. **ثنائية اللغة ودعم كامل للـ RTL**: العربية كواجهة رئيسية بخط `Tajawal`، مع زر تبديل فوري إلى الفرنسية.
7. **زر "الإبلاغ عن معلومة غير صحيحة"**: نموذج لتقديم التصحيحات مع إرفاق رابط المصدر الرسمي كشرط إلزامي.
8. **فضاء المكلفين بالموقع (Moderator Portal) — واجهة تجريبية غير مفعّلة للإدارة الإنتاجية**:
   - لوحة حكامة مخصصة لمدققي البيانات والمشرفين الأكاديميين.
   - طابور معالجة البلاغات مع مطابقة الروابط الرسمية.
   - محرر بيانات سريع للمؤسسات مع سجل محلي مؤقت للجلسة؛ لا يمثل Audit Trail دائماً أو غير قابل للتلاعب.
9. **واجهة إدارة تجريبية (Demo Admin) — لا تستخدم لإدارة بيانات إنتاجية**: لإضافة المؤسسات وتوثيق مصادرها وتصدير البيانات كـ JSON.
10. **قسم المواعيد الرسمية الموثقة**: عرض المواعيد الصادرة ببلاغات أو مراسيم معلنة فقط.
11. **صفحة ميثاق البيانات**: شرح حدود النموذج وإخلاء المسؤولية القانونية.

## 🛡️ 3. مبادئ البيانات المفتوحة والنزاهة
- **الأولوية المطلقة للبيانات المفتوحة**: بيانات `data.gov.ma` وبوابات قطاع التعليم العالي الرسمية (`enssup.gov.ma`).
- **صفر تخمين (Zero Hallucination)**: إذا لم يتوفر هاتف أو بريد معتمد رسمياً في المنشورات العامة، يُترك فارغاً ويُشار إليه بـ "غير متاح".
- **عدم جمع بيانات شخصية**: لا طلب لكلمات مرور ولا بيانات تسجيل دخول الطلبة.
- **إخلاء مسؤولية صريح**: المنصة نموذج تجريبي مستقل ولا تدعي تمثيل الجامعات أو الوزارة.

## 🏗️ 4. المعمارية الحالية

المستودع الحالي يحتوي على واجهة أمامية مبنية باستخدام:

- React 19 وTypeScript
- Vite
- Tailwind CSS
- Firebase ضمن الاعتماديات، لكن وجود الحزمة لا يعني أن المصادقة أو خدمات Firebase مهيأة أو مستخدمة فعلياً.
- Progressive Web App عبر `vite-plugin-pwa`

**لا توجد حالياً خدمة Backend أو قاعدة بيانات خادمية موثقة ضمن شجرة الملفات.** لذلك فإن بعض الوظائف الإدارية والتقارير والتقييمات تعتمد على حالة الواجهة و`localStorage`، ولا ينبغي اعتبارها تخزيناً مركزياً أو موثوقاً.

## 🚀 5. التثبيت والتشغيل

يتطلب التشغيل المحلي Node.js متوافقاً مع إصدار Vite المستخدم وnpm.

```bash
git clone https://github.com/Ifru-team/Jami3ati.git
cd Jami3ati
npm install
npm run dev
```

لإنشاء نسخة الإنتاج:

```bash
npm run lint
npm run build
npm run preview
```

## 🧪 6. الاختبارات والتحقق

سير العمل الحالي في GitHub Actions يتحقق من TypeScript وينشئ نسخة الإنتاج للواجهة الأمامية. لا توجد حالياً اختبارات Backend في هذا المستودع، لذلك لا يعلن CI عن اختبار خدمة خلفية غير موجودة.

## ⚖️ 7. حدود النموذج والآفاق المستقبلية
- **ما هو موثق ومحقق الآن**: جامعة محمد الخامس بالرباط، ENSIAS، وجامعة القاضي عياض بمراكش.
- **ما يحتاج اتفاقاً رسمياً أو تكاملاً مستقبلياً**: الشراكة مع الجامعات الأخرى (جامعة الحسن الثاني، سيدي محمد بن عبد الله، ابن زهر، إلخ)، وإمكانية توفير API رسمي بالتعاون مع بوابة `data.gov.ma`.
